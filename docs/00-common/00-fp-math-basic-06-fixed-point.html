不动点与递归 - 理解递归的本质

前置知识：建议先阅读 Lambda 演算 和 类型理论

一、为什么需要不动点？

在 Lambda 演算中，函数没有名字，如何实现递归？

// 问题：如何在 Lambda 演算中定义递归函数？
// 例如：阶乘函数
// fact n = if n == 0 then 1 else n * fact (n-1)

// 在有名字的语言中：
function fact(n) {
  return n === 0 ? 1 : n * fact(n - 1);
}

// 在 Lambda 演算中，函数没有名字，怎么递归？
// 答案：使用不动点组合子（Y Combinator）

二、不动点的定义

不动点（Fixed Point）是一个值，经过函数变换后保持不变：

x 是 f 的不动点 ⇔ f(x) = x 
// 数学中的不动点示例
// f(x) = x²
// 不动点：x = 0, x = 1
// 因为 0² = 0, 1² = 1

// g(x) = x + 1
// 不动点：不存在（除了无穷远处）

// h(x) = 2x / 3
// 不动点：x = 0
// 因为 2*0/3 = 0

不动点定理

对于连续函数 f: [a, b] → [a, b]，必有一个不动点（巴拿赫不动点定理的简化版本）。

三、Y 组合子

Y 组合子（Y Combinator）是一个用于在 Lambda 演算中实现递归的组合子。

3.1 定义

Y = λf. (λx. f (x x)) (λx. f (x x)) 
// Y 组合子的类型
// Y :: (a -> a) -> a

// Y 的作用
// Y F = F (Y F)
// 即：Y f 是 f 的不动点
// f (Y f) = Y f

3.2 为什么 Y 能实现递归？

// 让我们推导：Y F = F (Y F)

// 展开 Y 的定义
Y F
= (λf. (λx. f (x x)) (λx. f (x x))) F
= (λx. F (x x)) (λx. F (x x))          // Beta 归约
= F ((λx. F (x x)) (λx. F (x x)))      // 再次 Beta 归约
= F (Y F)                               // 替换回去

// 验证：令 fact = Y F
fact
= Y F
= F (Y F)
= F (fact)                              // 递归调用！

3.3 编程实现 Y

// JavaScript 实现 Y 组合子
const Y = (f: (fn: (x: any) => any) => (x: any) => any) => {
  return (const x: any) => f(x(x))(
         (const x: any) => f(x(x))
       );
};

// 使用 Y 定义阶乘
const factGen = (fact: (n: number) => number) => {
  return (n: number): number =>
    n === 0 ? 1 : n * fact(n - 1);
};

const fact = Y(factGen);

console.log(fact(5));  // 120

四、Z 组合子（严格版本）

Y 组合子在非严格求值语言（如 Haskell）中工作正常，但在严格求值语言（如 JavaScript）中会无限递归。Z 组合子解决了这个问题：

Z = λf. (λx. f (λy. x x y)) (λx. f (λy. x x y)) 
// Z 组合子：严格求值环境中的递归
const Z = (f: (fn: (x: any) => any) => (x: any) => any) => {
  return (const x: any) => f((y: any) => x(x)(y))(
         (const x: any) => f((y: any) => x(x)(y))
       );
};

// 使用 Z 定义阶乘
const factGen = (fact: (n: number) => number) => {
  return (n: number): number => {
    console.log("computing fact(" + n + ")");
    return n === 0 ? 1 : n * fact(n - 1);
  };
};

const fact = Z(factGen);

console.log(fact(5));
// 正常工作，不会无限递归

五、递归与不动点

递归的本质是求解函数方程：

fact = F(fact)

其中 F 是一个函数生成器（接受一个递归函数，返回一个新的递归函数）。

// 递归方程
// fact = λn. if n==0 then 1 else n * fact(n-1)

// 重写为不动点形式
// fact = F(fact)
// 其中 F = λf. λn. if n==0 then 1 else n * f(n-1)

// fact 是 F 的不动点
// fact = Y F

// 斐波那契数列
// fib = λn. if n<=1 then n else fib(n-1) + fib(n-2)
// fib = F(fib)
// fib = Y F

const fibGen = (fib: (n: number) => number) => {
  return (n: number): number =>
    n <= 1 ? n : fib(n - 1) + fib(n - 2);
};

const fib = Y(fibGen);
console.log(fib(10));  // 55

六、尾递归优化

递归可能导致栈溢出。尾递归优化（TCO）将递归转换为迭代。

6.1 普通递归 vs 尾递归

// 普通递归：计算结果需要等待递归返回
function fact(n) {
  if (n === 0) return 1;
  return n * fact(n - 1);  // 需要保存 n，等待递归返回
}

// 尾递归：递归调用是最后一步操作
function factTail(n, acc = 1) {
  if (n === 0) return acc;
  return factTail(n - 1, n * acc);  // 最后一步，直接返回
}

6.2 为什么尾递归可以优化？

// 普通递归的调用栈
// fact(5)
// 5 * fact(4)
// 5 * (4 * fact(3))
// 5 * (4 * (3 * fact(2)))
// 5 * (4 * (3 * (2 * fact(1))))
// 5 * (4 * (3 * (2 * 1)))
// 120
// 栈深度：O(n)

// 尾递归的调用栈
// factTail(5, 1)
// factTail(4, 5)
// factTail(3, 20)
// factTail(2, 60)
// factTail(1, 120)
// factTail(0, 120)
// 120
// 栈深度：O(1)，可以优化为循环

6.3 在 FP 中实现尾递归

// Haskell：天生的尾递归优化
-- fact n = go n 1
--   where
--     go 0 acc = acc
--     go n acc = go (n-1) (n * acc)

// JavaScript：使用 Trampoline 手动优化
const  trampoline = (fn: () => any): any => {
  let result = fn();
  while (typeof result === 'function') {
    result = result();
  }
  return result;
};

const factTail = (n: number, acc: number = 1): (() => any) | number => {
  if (n === 0) return acc;
  return () => factTail(n - 1, n * acc);
};

const result =  trampoline (() => factTail(100000));
console.log(result);  // 不会栈溢出！

七、递归与数学归纳法

递归和数学归纳法本质上是相同的：

数学归纳法 递归函数
基例：P(0) 为真 递归终止条件
归纳假设：假设 P(k) 为真 递归调用假设
归纳步骤：证明 P(k+1) 递归调用返回 
// 数学归纳法证明：1 + 2 + ... + n = n(n+1)/2
// 基例：n = 1, 1 = 1*2/2 = 1 ✓
// 归纳假设：假设 1+2+...+k = k(k+1)/2
// 归纳步骤：1+2+...+(k+1) = (1+...+k) + (k+1)
//                     = k(k+1)/2 + (k+1)
//                     = (k+1)(k/2 + 1)
//                     = (k+1)(k+2)/2
//                     = (k+1)((k+1)+1)/2 ✓

// 对应的递归函数
const sum = (n: number): number =>
  n === 0 ? 0 : n + sum(n - 1);

// sum(n) = n(n+1)/2
