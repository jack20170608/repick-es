函数基础 - 从数学到编程

前置知识：建议先阅读 集合论基础

一、函数的形式化定义

在数学中，函数是集合之间的一种特殊关系：

f: A → B

这表示 f 是一个从集合 A（定义域）到集合 B（值域）的函数。

函数的三个要素

  1. 定义域（Domain）：输入的集合 A
  2. 值域（Codomain）：输出的集合 B
  3. 对应规则（Rule）：每个 A 中的元素如何对应到 B 中的元素
// 数学函数：f(x) = x²
// f: ℕ → ℕ
f(x) = x * x

// 在编程中
const f = (x: number): number => x * x;
// 类型: (number) => number

二、函数的分类

2.1 单射（Injective / One-to-One）

不同的输入产生不同的输出：

∀x₁, x₂ ∈ A, x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂) 
// 单射示例：f(x) = 2x + 1
// 1 → 3, 2 → 5, 3 → 7, ...
// 不同的输入永远不会得到相同的输出

const isInjective = (f: (x: number) => number): boolean => {
  // 测试实现...
};

// 非单射示例：f(x) = x²
// f(2) = 4, f(-2) = 4  // 不同的输入产生相同输出

2.2 满射（Surjective / Onto）

值域中的每个元素都有对应的输入：

∀y ∈ B, ∃x ∈ A 使得 f(x) = y 
// 满射示例：f(x) = x + 1
// f: ℕ → ℕ₊ (自然数到正自然数)
// 每个正自然数都有对应的前驱

// 非满射示例：f(x) = x²
// f: ℕ → ℕ
// 2, 3, 5, 6, ... 没有对应的自然数平方根

2.3 双射（Bijective）

既是单射又是满射，即「一一对应」：

双射 ⇔ 单射 ∧ 满射

双射函数是可逆的，存在逆函数 f⁻¹。

// 双射示例：f(x) = x + 1
// f: ℕ → ℕ₊ 是双射
// 逆函数：f⁻¹(y) = y - 1

const add1 = (x: number): number => x + 1;
const sub1 = (x: number): number => x - 1;

// 验证：f⁻¹(f(x)) = x
// sub1(add1(x)) = sub1(x + 1) = x

三、函数复合

函数复合是 FP 的核心操作：

(g ∘ f)(x) = g(f(x))

先执行 f，再执行 g。

// 数学表示：g ∘ f
// f: A → B
// g: B → C
// g ∘ f: A → C

// 编程实现
const compose = <A, B, C>(g: (b: B) => C, f: (a: A) => B) =>
  (a: A): C => g(f(a));

// 示例
const add1 = (x: number) => x + 1;
const double = (x: number) => x * 2;
const add1ThenDouble = compose(double, add1);

console.log(add1ThenDouble(3));  // (3 + 1) * 2 = 8

结合律

函数复合满足结合律：

h ∘ (g ∘ f) = (h ∘ g) ∘ f 
// 结合律示例
const f = (x: number) => x + 1;
const g = (x: number) => x * 2;
const h = (x: number) => x - 3;

// h ∘ (g ∘ f)
const left = compose(h, compose(g, f));

// (h ∘ g) ∘ f
const right = compose(compose(h, g), f);

// 结果相同：left(x) === right(x)

四、恒等函数与常数函数

4.1 恒等函数（Identity Function）

id_A: A → A, id_A(x) = x 
// 恒等函数
const identity = <T>(x: T): T => x;

console.log(identity(5));        // 5
console.log(identity("hello"));  // "hello"
console.log(identity({a: 1}));   // {a: 1}

// 恒等函数的性质
// compose(f, id) = f
// compose(id, f) = f

4.2 常数函数（Constant Function）

const_k: A → B, const_k(x) = k

无论输入是什么，都返回同一个常数。

// 常数函数
const constant = <T, K>(k: K) => (x: T): K => k;

const always5 = constant(5);
console.log(always5(1));  // 5
console.log(always5(100)); // 5
console.log(always5("x")); // 5

五、偏函数与全函数

5.1 全函数（Total Function）

定义域中的每个元素都有对应的输出：

// 全函数：所有输入都有定义
const add = (a: number, b: number): number => a + b;
// add(1, 2) = 3
// add(0, 0) = 0
// 任何两个数字相加都有定义

5.2 偏函数（Partial Function）

只有部分输入有定义：

// 偏函数：某些输入没有定义
const divide = (a: number, b: number): number => {
  if (b === 0) {
    throw new Error("Cannot divide by zero");
  }
  return a / b;
};
// divide(10, 2) = 5
// divide(10, 0) // 抛出错误！

// 在 FP 中，偏函数通常用 Maybe 表示
const safeDivide = (a: number, b: number): number | null =>
  b === 0 ? null : a / b;

六、闭包与高阶函数

6.1 闭包（Closure）

闭包是绑定了自由变量的函数：

// 闭包：函数携带了创建时的环境
const createAdder = (n: number): (x: number) => number => {
  return (x: number): number => x + n;
};

const add5 = createAdder(5);
const add10 = createAdder(10);

console.log(add5(3));   // 8
console.log(add10(3));  // 13

6.2 高阶函数（Higher-Order Function）

接受函数作为输入或输出的函数：

// 高阶函数示例

// 接受函数作为参数
const map = <T, U>(fn: (t: T) => U, arr: T[]): U[] =>
  arr.map(fn);

// 接受函数作为参数
const filter = <T>(pred: (t: T) => boolean, arr: T[]): T[] =>
  arr.filter(pred);

// 返回函数
const curry = <T, U, V>(fn: (a: T, b: U) => V) =>
  (a: T) => (b: U): V => fn(a, b);

七、总结

概念 数学符号 编程对应
函数 f: A → B (a: A) => B
单射 不同的x，不同的f(x) Map 结构
满射 每个y都有对应的x 覆盖所有情况
双射 单射 + 满射 可逆函数
复合 g ∘ f compose(g, f)
恒等 id(x) = x identity(x)
