一、为什么学范畴论？

范畴论是 FP 的「元语言」：

  • Functor、Applicative、Monad 都来自范畴论
  • 理解它们为什么这样设计，而不是死记硬背
  • 学习抽象思考的方式

二、范畴的定义

范畴（Category）由两部分组成：

  1. 对象（Objects）：一组「东西」
  2. 态射（Morphisms）：对象之间的「箭头」

范畴的三条公理

公理 说明
恒等态射 每个对象都有 id: A → A
结合律 (f ∘ g) ∘ h = f ∘ (g ∘ h)
闭合性 若 f: A → B, g: B → C，则 g ∘ f: A → C 
// 范畴示例：Set（集合范畴）
// 对象：所有集合
// 态射：所有函数

// 范畴示例：Type（类型范畴）
// 对象：所有类型（如 number, string, []）
// 态射：所有函数（如 (x: number) => string）

// 范畴示例：Hask（Haskell 类型范畴）
// 对象：Haskell 类型
// 态射：Haskell 函数

三、函子（Functor）

函子（Functor）是范畴之间的「保持结构的映射」。

3.1 定义

函子 F: C → D 包含：

  1. 对象映射：对 C 中的每个对象 A，映射到 D 中的对象 F(A)
  2. 态射映射：对 C 中的每个态射 f: A → B，映射到 D 中的态射 F(f): F(A) → F(B)

3.2 函子公理

// 1. 保持恒等态射
// F(id_A) = id_F(A)

// 2. 保持复合
// F(f ∘ g) = F(f) ∘ F(g)

3.3 编程中的 Functor

// JavaScript: Array 是 Functor
// map :: (a -> b) -> [a] -> [b]
[1, 2, 3].map(x => x * 2)  // [2, 4, 6]

// TypeScript: 包装类型
class Box<A> {
  constructor(private value: A) {}

  map<B>(fn: (a: A) => B): Box<B> {
    return new Box(fn(this.value));
  }
}

const box = new Box(5);
box.map(x => x * 2)  // Box(10)
box.map(x => x.toString())  // Box("5")

// Maybe Functor
type Maybe<A> = A | null;

const mapMaybe = <A, B>(fn: (a: A) => B, ma: Maybe<A>): Maybe<B> =>
  ma === null ? null : fn(ma);

mapMaybe(x => x * 2, 5)   // 10
mapMaybe(x => x * 2, null)  // null

四、应用函子（Applicative）

Applicative 是「带参数函数」的 Functor。

4.1 动机

// Functor 可以处理：fn :: a -> b, fa :: F a
// 但如果 fn 也在上下文中呢？
// fn :: F (a -> b), fa :: F a

// Functor 解决不了这个问题！
// 需要 Applicative

4.2 定义

方法 类型 说明
pure a → F a 把值放入上下文
ap F (a → b) → (F a) → F b 应用上下文中 的函数

4.3 编程中的 Applicative

// JavaScript: 实现 Applicative Box
class Box<A> {
  constructor(private value: A) {}

  map<B>(fn: (a: A) => B): Box<B> {
    return new Box(fn(this.value));
  }

  // Applicative 方法
  ap<B>(fab: Box<(a: A) => B>): Box<B> {
    return fab.map(fn => fn(this.value));
  }

  static pure<A>(a: A): Box<A> {
    return new Box(a);
  }
}

// 使用
const add = (a: number) => (b: number): number => a + b;
Box.pure(add).ap(Box.pure(5)).ap(Box.pure(3))
// Box(8)

五、单子（Monad）

Monad 是「扁平化」的 Monoidal Functor。

5.1 动机：处理嵌套上下文

// Functor: F a -> F b
// Applicative: F (a -> b) -> F a -> F b

// 但如果有 F (F a) 呢？
// 嵌套的数组？ Promise>？

// 需要 flatten/join

5.2 定义

方法 类型 说明
of / pure a → M a 把值放入 Monad
flatMap / bind M a → (a → M b) → M b 链式操作，平滑嵌套

5.3 编程中的 Monad

// JavaScript: Promise 是 Monad
// Promise.resolve(a) = pure
// Promise.then(fn) = flatMap

Promise.resolve(5)
  .then(x => x * 2)
  .then(x => Promise.resolve(x + 1))
  .then(console.log);  // 11

// Array 也是 Monad
[1, 2, 3]
  .flatMap(x => [x, x * 10])
  // [1, 10, 2, 20, 3, 30]

// Maybe Monad
type Maybe<A> = A | null;

const pure = <A>(a: A): Maybe<A> => a;
const flatMap = <A, B>(ma: Maybe<A>, fn: (a: A) => Maybe<B>): Maybe<B> =>
  ma === null ? null : fn(ma);

// 链式操作
flatMap(
  flatMap(
    pure(5),
    x => x > 0 ? x : null  // 过滤负数
  ),
  x => x * 2 > 0 ? x * 2 : null
)  // 10

5.4 Monad 定律

// 1. 左单位律
// pure(a).flatMap(f) ≡ f(a)

// 2. 右单位律
// m.flatMap(pure) ≡ m

// 3. 结合律
// m.flatMap(f).flatMap(g) ≡ m.flatMap(x => f(x).flatMap(g))

七、实战：整合所有概念

// 完整的函子层级

// Functor: 可以 map
// fmap :: (a -> b) -> F a -> F b

// Applicative: 可以 ap + of
// ap :: F (a -> b) -> F a -> F b
// of :: a -> F a

// Monad: 可以 flatMap + of
// flatMap :: F a -> (a -> F b) -> F b
// of :: a -> F a

// 继承关系：Monad ⊃ Applicative ⊃ Functor
