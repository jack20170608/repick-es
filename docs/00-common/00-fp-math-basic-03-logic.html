命题与谓词逻辑 - 理解条件与类型约束

前置知识：建议先阅读 集合论基础 和 函数基础

一、为什么学逻辑？

逻辑是 FP 的根基：

  • 类型系统本质上是一种静态逻辑断言
  • 模式匹配是逻辑匹配的实现
  • 类型类是逻辑约束的表达
  • 证明助手（Coq、Lean）直接基于类型论

二、命题逻辑

命题是一个要么为真要么为假的陈述：

// 命题示例
P: "今天下雨"        // 可以为真或为假
Q: "2 + 2 = 4"       // 永真
R: "2 + 2 = 5"       // 永假

// 在编程中，命题就是返回 Boolean 的表达式
const isEven = (n: number): boolean => n % 2 === 0;

2.1 基本逻辑运算

运算 符号 定义
否定 ¬P P 为真时 ¬P 为假
合取 P ∧ Q 两者都为真时才为真
析取 P ∨ Q 至少有一个为真即为真
蕴含 P → Q P 为真时 Q 必须为真
等价 P ↔ Q P 和 Q 同真同假

2.2 真值表

// 否定 (NOT)
// P    ¬P
// T    F
// F    T

// 合取 (AND)
// P    Q    P ∧ Q
// T    T    T
// T    F    F
// F    T    F
// F    F    F

// 析取 (OR)
// P    Q    P ∨ Q
// T    T    T
// T    F    T
// F    T    T
// F    F    F

// 蕴含 (IMPLIES)  - 重点！
// P    Q    P → Q
// T    T    T
// T    F    F
// F    T    T  ← 注意：false ⇒ true 为真！
// F    F    T  ← 注意：false ⇒ false 为真！

2.3 编程中的逻辑运算

// JavaScript 中的逻辑运算
const P = true;
const Q = false;

// 否定
!P  // false

// 合取 (AND)
P && Q  // false

// 析取 (OR)
P || Q  // true

// 蕴含的逻辑等价
// P → Q 等价于 !P || Q
const implies = (P: boolean, Q: boolean): boolean => !P || Q;

// 德摩根定律
// !(P && Q) === (!P || !Q)
// !(P || Q) === (!P && !Q)

三、谓词逻辑

谓词是带有变量的命题，返回值依赖于变量的值：

// 谓词示例
// P(x): "x 是偶数"
const isEven = (x: number): boolean => x % 2 === 0;

isEven(4)  // true
isEven(5)  // false

// Q(x, y): "x < y"
const lessThan = (x: number, y: number): boolean => x < y;

// R(x): "x 是正数"
const isPositive = (x: number): boolean => x > 0;

3.1 量词

量词用于表达「关于多少」的信息：

量词 符号 含义 编程对应
全称量词 ∀ 「对于所有」 Array.every()
存在量词 ∃ 「存在至少一个」 Array.some()
唯一量词 ∃! 「恰好存在一个」 filter().length === 1 
// 全称量词：∀x, P(x)
// "所有自然数都是非负的"
const allNonNegative = (nums: number[]): boolean =>
  nums.every(n => n >= 0);

// 存在量词：∃x, P(x)
// "存在一个偶数"
const hasEven = (nums: number[]): boolean =>
  nums.some(n => n % 2 === 0);

// 唯一量词：∃!x, P(x)
// "恰好存在一个负数"
const hasExactlyOneNegative = (nums: number[]): boolean =>
  nums.filter(n => n < 0).length === 1;

3.2 量词的否定

重要的等价关系：

¬∀x P(x) ≡ ∃x ¬P(x) ¬∃x P(x) ≡ ∀x ¬P(x) 
// 量词否定的编程意义

// "不是所有元素都是偶数"
// ≡ "存在至少一个元素不是偶数"
const notAllEven = (nums: number[]): boolean =>
  !nums.every(n => n % 2 === 0);

const existsNotEven = (nums: number[]): boolean =>
  nums.some(n => n % 2 !== 0);

// "没有负数"
// ≡ "所有元素都是非负的"
const noNegatives = (nums: number[]): boolean =>
  !nums.some(n => n < 0);

const allNonNegative = (nums: number[]): boolean =>
  nums.every(n => n >= 0);

四、逻辑与类型系统

类型系统可以被理解为一种静态的谓词逻辑：

4.1 类型作为命题

// 类型检查通过 = 命题被证明
// 编写代码就是构造证明

// 命题：x 是整数
const x: number = 5;

// 命题：str 是字符串
const str: string = "hello";

// 命题：user 是 User 类型
interface User { name: string; age: number; }
const user: User = { name: "Alice", age: 30 };

4.2 函数类型作为蕴含

函数类型 A → B 可以理解为「如果 A，则 B」：

(A → B) ≡ "若 x 是 A 类型，则 f(x) 是 B 类型" 
// f: (x: number) => string
// 蕴含：number → string
// 含义：如果输入数字，输出字符串

const toString = (x: number): string => String(x);

// g: (x: number) => boolean
const isPositive = (x: number): boolean => x > 0;

4.3 Maybe 类型与偏函数

Maybe 类型处理「值可能不存在」的情况：

// Maybe a = Just a | Nothing
// 这对应逻辑中的"可能为假"

type Maybe<T> = T | null;

// 安全的除法：可能返回 null
const safeDivide = (a: number, b: number): number | null =>
  b === 0 ? null : a / b;

// 这相当于一个偏谓词
// P(x): "x 可以被安全地除"
// 不是所有输入都有定义（对应偏函数）

4.4 Either 类型与错误处理

Either 类型区分「成功」和「失败」两种情况：

// Either a b = Left a | Right b
// Left: 错误情况，Right: 成功情况

type Either<L, R> = { tag: 'Left', value: L } | { tag: 'Right', value: R };

// 安全的除法：明确返回错误
const safeDivide = (a: number, b: number): Either<string, number> =>
  b === 0
    ? { tag: 'Left', value: "Division by zero" }
    : { tag: 'Right', value: a / b };

// Either 对应逻辑中的"二选一"命题
// "要么成功，要么失败" = 排中律的实现

五、Curry-Howard 对应

这是逻辑与类型系统最深刻的联系：

类型论 逻辑学 说明
类型 A 命题 P 一个断言
项 M: A 命题 P 的证明 构造证据
A → B P → Q (蕴含) 函数/推导
A × B P ∧ Q (合取) 元组/且
A + B P ∨ Q (析取) 联合类型/或
Void / 0 ⊥ (假) 不可证明
Unit / 1 ⊤ (真) 平凡真
∀a. T ∀x. P(x) 全称量词
∃a. T ∃x. P(x) 存在量词 
// Curry-Howard 对应示例

// 类型：number
// 对应命题："存在一个 number"

// 类型：(a: number) => string
// 对应命题："若 a 是 number，则 result 是 string"

// 类型：[number, string]
// 对应命题："a 是 number 且 b 是 string"

// 类型：number | string
// 对应命题："a 是 number 或 a 是 string"

// 类型：never（不可达）
// 对应命题："假"（永假）

六、总结

逻辑概念 编程对应
命题 Boolean 表达式
谓词 返回 Boolean 的函数
∀（全称） Array.every()
∃（存在） Array.some()
函数类型 蕴含关系
