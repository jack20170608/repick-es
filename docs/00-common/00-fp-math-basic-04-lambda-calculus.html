Lambda 演算 - 函数式编程的理论基石

一、什么是 Lambda 演算？

Lambda 演算（λ-calculus）由 阿隆佐·丘奇（Alonzo Church）在 1936 年发明，是一套函数定义和应用的形式系统。

核心思想

一切皆函数，一切皆表达式。

  • 函数是一等公民（first-class citizen）
  • 函数可以接受函数作为参数
  • 函数可以返回函数作为结果
// Lambda 演算的语法
// λx. body  表示一个函数：输入 x，返回 body

// 示例：恒等函数
λx. x

// 示例：常数函数
λx. 5

// 示例：加法函数
λx. λy. x + y

二、语法定义

Lambda 演算的语法极其简洁，只有三种表达式：

2.1 语法糖

语法 名称 说明
x 变量 一个符号，表示参数
λx. M 抽象（Abstraction） 定义一个函数，x 是参数，M 是函数体
M N 应用（Application） 将函数 M 应用到参数 N 上

2.2 语法树

// 表达式：λx. (λy. x y)
// 树形结构：
//       λx.
//         λy.
//           (x y)
//             ↑   ↑
//          x    y (函数应用)

三、Alpha 转换

Alpha 转换（α-conversion）是指改变 bound 变量的名称：

λx. M ≡ λy. M[x/y]

其中 M[x/y] 表示把 M 中所有自由的 x 替换为 y。

// Alpha 转换示例
// λx. x  ≡  λy. y
// λx. (λy. x y)  ≡  λa. (λb. a b)

// 为什么要改名字？避免捕获
// λx. (λx. x)  中的内层 x 不会和外层 x 冲突
// 因为它们是不同的绑定作用域

四、Beta 归约

Beta 归约（β-reduction）是函数应用的核心操作：

(λx. M) N → M[x/N]

把函数体中的 x 替换为参数 N。

4.1 简单示例

// (λx. x) y  →  y
// 把 x 替换为 y

// (λx. λy. x + y) 3 4  →  (λy. 3 + y) 4  →  3 + 4  →  7
// 两次 Beta 归约

4.2 编程实现

// 简单的 Lambda 演算解释器

// 表达式类型
type Expr =
  | { tag: 'Var', name: string }
  | { tag: 'Abs', param: string, body: Expr }
  | { tag: 'App', fn: Expr, arg: Expr };

// Beta 归约
function betaReduce(expr: Expr): Expr {
  switch (expr.tag) {
    case 'Var':
      return expr;

    case 'Abs':
      return {
        ...expr,
        body: betaReduce(expr.body)  // 归约函数体
      };

    case 'App': {
      const fn = betaReduce(expr.fn);
      const arg = betaReduce(expr.arg);

      // 如果函数是一个抽象，执行 Beta 归约
      if (fn.tag === 'Abs') {
        return substitute(fn.body, fn.param, arg);
      }

      return { tag: 'App', fn, arg };
    }
  }
}

// 替换：把 body 中的 var 替换为 value
function substitute(body: Expr, var: string, value: Expr): Expr {
  switch (body.tag) {
    case 'Var':
      return body.name === var ? value : body;

    case 'Abs':
      // Alpha 转换：避免变量捕获
      if (body.param === var) return body;
      const newParam = freshVar(body.param, value);
      const newBody = substitute(
        substitute(body.body, body.param, { tag: 'Var', name: newParam }),
        var,
        value
      );
      return { tag: 'Abs', param: newParam, body: newBody };

    case 'App':
      return {
        tag: 'App',
        fn: substitute(body.fn, var, value),
        arg: substitute(body.arg, var, value)
      };
  }
}

五、Eta 转换

Eta 转换（η-conversion）描述了函数的 extensionality（外延性）：

λx. (M x) ≡ M

前提：x 不在 M 中自由出现。

// Eta 转换示例
// λx. (f x)  ≡  f
// 如果一个函数接受参数 x，然后立即把 f 应用到 x 上
// 那么它就等价于 f 本身

// JavaScript 示例
const f = x => x + 1;
const g = x => f(x);  // g ≡ f

六、Church 编码

Church 编码是用 Lambda 演算表示基本数据的方法。

6.1 Church 布尔值

// Church 布尔值
const TRUE  = λx. λy. x;   // 选择第一个参数
const FALSE = λx. λy. y;   // 选择第二个参数

// NOT
const NOT = λp. λx. λy. p y x;

// AND
const AND = λp. λq. p q p;

// OR
const OR  = λp. λq. p p q;

// IF
const IF = λp. λx. λy. p x y;

6.2 Church 数字

// Church 数字：n = λf. λx. fⁿ(x)
const ZERO  = λf. λx. x;
const ONE   = λf. λx. f x;
const TWO   = λf. λx. f (f x);
const THREE = λf. λx. f (f (f x));
const FOUR  = λf. λx. f (f (f (f x)));

// SUCC（后继）
const SUCC = λn. λf. λx. f (n f x);

// ADD（加法）
const ADD = λm. λn. λf. λx. m f (n f x);

// MULT（乘法）
const MULT = λm. λn. λf. m (n f);

// PRED（前驱）
const PRED = λn. λf. λx.
  n (λg. λh. h (g f)) (λy. x) (λy. y);

6.3 Church 列表

// Church 列表
// [a, b, c] = λc. λn. c a (c b (c c n))

// CONS（构造）
const CONS = λh. λt. λc. λn. c h (t c n);

// CAR（取头）
const CAR = λp. p (λh. λt. h);

// CDR（取尾）
const CDR = λp. p (λh. λt. t);

// NIL（空列表）
const NIL = λc. λn. n;

// IS_NIL（判断空）
const IS_NIL = λp. p (λh. λt. FALSE) TRUE;

七、编程语言中的 Lambda 演算

7.1 JavaScript

// JavaScript 箭头函数就是 Lambda 表达式

// λx. x  →  x => x
const identity = x => x;

// λx. λy. x + y  →  x => y => x + y
const add = x => y => x + y;

// 应用：(add 3) 4  →  7
console.log(add(3)(4));  // 7

7.2 Haskell

-- Lambda 表达式
-- λx -> x
identity = \x -> x

-- λx -> λy -> x + y
add = \x -> \y -> x + y

-- 应用：add 3 4
-- :t add  →  Num a => a -> a -> a

7.3 Python

# Lambda 表达式
# lambda x: x
identity = lambda x: x

# lambda x: lambda y: x + y
add = lambda x: lambda y: x + y

# 应用：add(3)(4)
print(add(3)(4))  # 7

八、总结

概念 说明
λx. M 抽象，定义函数
M N 应用，调用函数
α 转换 变量重命名
β 归约 函数应用（核心操作）
η 转换 函数外延性
Church 编码 用函数表示数据

Lambda 演算是所有函数式编程语言的的理论基础。理解了 Lambda 演算，你就理解了 FP 的本质。下一章我们将学习类型理论，了解如何给 Lambda 演算加上类型约束。
