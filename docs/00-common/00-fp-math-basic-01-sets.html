集合论基础 - 函数式编程的数学地基

前置知识：无。本文是函数式编程数学基础系列的第一篇。

一、为什么学集合论？

集合论是现代数学的基石，也是理解函数式编程的起点。在 FP 中：

  • 类型 就是集合
  • 函数 是集合之间的映射
  • 泛型 是集合的运算

理解了集合论，你就理解了类型系统的本质。

二、集合的基本概念

2.1 什么是集合？

集合（Set）是互不相同的对象的无序聚集。

// 集合的表示
A = {1, 2, 3}          // 有限集合
B = {1, 2, 3, ...}    // 无限集合
N = {0, 1, 2, 3, ...} // 自然数集合
∅ = {}                // 空集

2.2 集合的关系

关系 符号 定义
属于 ∈ x ∈ A 表示 x 是集合 A 的元素
子集 ⊆ A ⊆ B 表示 A 的所有元素都在 B 中
真子集 ⊂ A ⊂ B 表示 A ⊆ B 且 A ≠ B
相等 = A = B 表示 A ⊆ B 且 B ⊆ A

2.3 集合的运算

// 并集 A ∪ B：属于 A 或属于 B 的元素
A = {1, 2, 3}
B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}

// 交集 A ∩ B：同时属于 A 和 B 的元素
A ∩ B = {3}

// 差集 A \ B：属于 A 但不属于 B 的元素
A \ B = {1, 2}

// 补集 Aᶜ：属于全集 U 但不属于 A 的元素
U = {1, 2, 3, 4, 5}
Aᶜ = {4, 5}

三、笛卡尔积

笛卡尔积是理解元组和函数参数的基础：

A × B = {(a, b) | a ∈ A 且 b ∈ B} 
// 笛卡尔积的例子
A = {1, 2}
B = {x, y}
A × B = {(1, x), (1, y), (2, x), (2, y)}

// 在编程中的对应
// type Pair = [number, string] 相当于 A × B
// type User = { name: string, age: number } 相当于 {name} × {age}

为什么重要？

函数的参数类型就是输入集合的笛卡尔积：

f: (A₁ × A₂ × ... × Aₙ) → B

这正是我们定义多参数函数类型的方式！

四、关系

关系是集合论中连接数学和编程的桥梁：

4.1 关系的定义

关系是笛卡尔积的子集：

R ⊆ A × B 
// 关系示例
// "小于"关系：R = {(x, y) | x < y}
// 在编程中：x < y 返回布尔值

// "等于"关系：R = {(x, x) | x ∈ A}
// 在编程中：x === y 返回布尔值

4.2 关系的性质

性质 定义 编程对应 示例
自反性 ∀x ∈ A, (x, x) ∈ R x === x 相等关系 (=)
对称性 若 (x, y) ∈ R 则 (y, x) ∈ R x === y ⇒ y === x 相等关系 (=)
传递性 若 (x, y) ∈ R 且 (y, z) ∈ R 则 (x, z) ∈ R x < y 且 y < z ⇒ x < z 小于关系 (<)
反对称性 若 (x, y) ∈ R 且 (y, x) ∈ R 则 x = y x ≤ y 且 y ≤ x ⇒ x === y 小于等于关系 (≤)

4.3 关系的运算

关系作为集合，也可以进行运算：

逆关系

R⁻¹ = {(b, a) | (a, b) ∈ R} 
// 逆关系示例
R = {(1, 2), (1, 3), (2, 3)}     // "小于"关系
R⁻¹ = {(2, 1), (3, 1), (3, 2)}  // "大于"关系

复合关系

R ∘ S = {(a, c) | ∃b 使得 (a, b) ∈ R 且 (b, c) ∈ S} 
// 复合关系示例
R = {(1, 2), (2, 3)}      // "是...的父亲"
S = {(2, 3), (3, 4)}      // "是...的母亲"
R ∘ S = {(1, 3), (2, 4)} // "是...的外婆"

4.4 特殊关系类型

等价关系

满足自反、对称、传递的关系：

// 等价关系的例子
// 1. 数值相等：a = b
// 2. 字符串相等：a === b
// 3. 同余关系：a ≡ b (mod n) —— 模 n 同余
// 4. 平面几何中的全等、相似

// 在编程中：类型系统的相等
type Equals<T> = (a: T, b: T) => boolean

偏序关系

满足自反、反对称、传递的关系：

// 偏序关系的例子
// 1. 小于等于：a ≤ b
// 2. 集合包含：A ⊆ B
// 3. 整除：a | b （a 整除 b）
// 4. 字符串前缀：a 是 b 的前缀

// 在编程中：类型的子类型关系
// string extends string ✓ 自反
// string extends number && number extends string ⇒ string = number ✗ 反对称

全序关系

偏序关系 + 任意两元素可比：

// 全序关系的例子
// 1. 数值大小：a ≤ b
// 2. 字典序：字符串比较
// 3. 时间顺序：先后关系

// 非全序的例子：集合的包含关系
// {1} ⊆ {2}？不可比较！

4.5 关系的编程应用

// 关系在编程中的实际应用

// 1. 验证关系：检查是否满足某种关系
const isLessThan = (a: number, b: number): boolean => a < b
// isLessThan(1, 2) === true

// 2. 等价关系：自定义相等
const equalsByLength = (a: string, b: string): boolean => a.length === b.length
// equalsByLength("hi", "yo") === true

// 3. 偏序关系：依赖排序
const deps = {
  'css': ['html'],
  'js': ['html'],
  'html': [],
}
// html ≤ css, html ≤ js —— 偏序关系

// 4. 等价类：分区(groupBy)
const groupBy = <T>(arr: T[], eq: (a: T, b: T) => boolean): T[][] => {
  // eq 是等价关系，将数组划分为等价类
}
// groupBy([1,2,3,4], (a,b) => a % 2 === b % 2)
// 结果: [[1,3], [2,4]] —— 奇数一组，偶数一组

五、函数：特殊的关系

函数是关系的一种特殊类型，它满足：

  1. 定义域（Domain）：所有可能的输入
  2. 值域（Codomain）：所有可能的输出
  3. 唯一性：每个输入有且仅有一个输出
f: A → B

表示 f 是从集合 A 到集合 B 的函数。

// 函数的类型签名
// f: A → B 意味着：
// - 输入：类型 A 的值
// - 输出：类型 B 的值

// 在 TypeScript 中
function add(a: number, b: number): number { return a + b; }
// 类型: (number × number) → number

// 在 Haskell 中
-- add :: Num a => a -> a -> a
-- add a b = a + b

六、幂集

幂集是一个集合的所有子集的集合：

P(A) = {X | X ⊆ A} 
// 幂集示例
A = {1, 2}
P(A) = {∅, {1}, {2}, {1, 2}}

// 幂集在编程中的应用
// Maybe a = Nothing | Just a  相当于 {∅, {a}}
// Either a b = Left a | Right b  相当于 {a} ∪ {b}

七、总结

概念 编程对应
集合 类型（Type）
元素 值（Value）
笛卡尔积 元组、参数列表
关系 布尔函数、断言
函数 纯函数
幂集 Maybe, Either 等类型构造
