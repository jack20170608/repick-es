类型理论 - 理解类型系统的本质

前置知识：建议先阅读 Lambda 演算

一、为什么需要类型系统？

类型系统是 静态的逻辑证明系统：

  • 在编译时检查代码的正确性
  • 防止运行时错误（如 null pointer）
  • 作为文档和约束
  • 实现 Curry-Howard 对应
// 没有类型系统：运行时可能出错
function getName(user) {
  return user.name.toUpperCase();  // user 可能是 null!
}

// 有类型系统：编译时就能发现错误
function getName(user: User): string {
  return user.name.toUpperCase();  // 编译器保证 user 不是 null
}

二、简单类型 Lambda 演算

简单类型 lambda 演算（Simply Typed Lambda Calculus, STLC）给 Lambda 演算加上了类型。

2.1 类型语法

// 类型语法
τ ::= α           // 类型变量（基类型）
    | τ → τ'      // 函数类型
    | (τ₁, τ₂)    // 积类型（可选）
    | Unit        // 单元类型（可选）

// 示例类型
Int               // 整数类型
String            // 字符串类型
Int → String      // 接受 Int，返回 String 的函数
(Int → Int) → Int // 接受 (Int → Int)，返回 Int 的函数

2.2 类型规则

规则 名称 说明
Var 变量规则 如果 x:A 在上下文中，则 x:A
Abs 抽象规则 如果 x:A 在上下文，且 M:B，则 λx.M : A → B
App 应用规则 如果 M:A → B 且 N:A，则 M N : B

三、多态类型与 Hindley-Milner

Hindley-Milner（HM）类型系统是 ML、Haskell 等语言的基础。

3.1 多态函数

// Haskell 中的多态函数
-- identity :: a -> a
identity x = x

-- 这里的 'a' 是类型变量，代表任意类型
-- identity 1  :: Int
-- identity "hello" :: String
-- identity [1,2,3] :: [Int]

3.2 类型推导

HM 系统可以自动推导表达式的类型：

// 示例：自动类型推导
-- let f = \x -> x + 1
-- 推导过程：
-- 1. x :: a (未知类型)
-- 2. x + 1 需要 Num a 约束
-- 3. 结果类型是 a
-- 4. f :: Num a => a -> a

// TypeScript 中的类型推导
const id = <T>(x: T): T => x;
// 编译器自动推导：id<T>(x: T): T

const map = <T, U>(fn: (t: T) => U, arr: T[]): U[] =>
  arr.map(fn);
// 编译器自动推导泛型参数

3.3 通用类型（Generalization）

// 通用类型示例
-- let id x = x
-- id :: a -> a

-- let foo x = id (id x)
-- foo :: a -> a
-- (id x) :: a
-- id (id x) :: a

// TypeScript
const id = <T>(x: T): T => x;
const foo = <T>(x: T): T => id(id(x));
// foo :: <T>(x: T) => T

四、代数数据类型（ADT）

ADT 是 FP 中最重要的类型构造方式。

4.1 和类型（Sum Type）

// Haskell: 使用 data 关键字定义和类型
-- Bool = True | False
-- Maybe a = Nothing | Just a
-- Either a b = Left a | Right b

-- TypeScript: 联合类型
type Maybe<T> = T | null;
type Either<L, R> = { tag: 'Left', value: L } | { tag: 'Right', value: R };

// 使用模式匹配
const safeDivide = (a: number, b: number): Either<string, number> =>
  b === 0
    ? { tag: 'Left', value: "Division by zero" }
    : { tag: 'Right', value: a / b };

4.2 积类型（Product Type）

// Haskell: 元组和记录
-- (Int, String)     -- 元组
-- data Point = Point { x :: Int, y :: Int }

// TypeScript: 接口和元组
type Point = { x: number; y: number };
type Pair = [number, string];

const point: Point = { x: 10, y: 20 };
const pair: Pair = [10, "hello"];

4.3 递归类型

// 列表的递归定义
-- data List a = Nil | Cons a (List a)
-- [1,2,3] = Cons 1 (Cons 2 (Cons 3 Nil))

// TypeScript: 链表
type List<T> =
  | { tag: 'Nil' }
  | { tag: 'Cons', head: T, tail: List<T> };

// 树
type Tree<T> =
  | { tag: 'Leaf', value: T }
  | { tag: 'Node', left: Tree<T>, right: Tree<T> };

五、类型类的约束

类型类（Type Class）实现了 ad-hoc 多态。

5.1 什么是类型类？

// Haskell: Eq 类型类
-- class Eq a where
--   (==) :: a -> a -> Bool
--   (/=) :: a -> a -> Bool

-- 实例：Int 的 Eq 实例
-- instance Eq Int where
--   (==) = primEqInt

// TypeScript: 接口 + 实现
interface Eq<T> {
  equals(a: T, b: T): boolean;
}

const numberEq: Eq<number> = {
  equals: (a, b) => a === b
};

const stringEq: Eq<string> = {
  equals: (a, b) => a === b
};

5.2 常用类型类

类型类 方法 含义
Eq (==), (/=) 可比较相等性
Ord (<), (>), compare 可排序
Show show 可转换为字符串
Read read 可从字符串解析
Functor fmap 可映射
Monad (>>=), return 可绑定

六、Curry-Howard 对应回顾

类型系统与逻辑的深刻对应：

类型 逻辑 说明
τ 命题 类型即命题
x: τ 假设 变量即假设
λx. M 证明 函数即证明
A → B A ⇒ B 函数类型即蕴含
A × B A ∧ B 元组即合取
A + B A ∨ B 联合类型即析取
0 / Void ⊥ 空类型即假
1 / Unit ⊤ 单元类型即真
∀α. τ ∀x. P(x) 多态即全称量词
∃α. τ ∃x. P(x) 存在类型即存在量词

七、总结

概念 说明
STLC 简单类型 lambda 演算
HM 类型系统 Hindley-Milner，支持类型推导
ADT 代数数据类型（和类型 + 积类型）
类型类 ad-hoc 多态，接口约束
Curry-Howard 类型 = 命题，函数 = 证明

类型理论是现代 FP 语言的核心。下一章我们将学习不动点与递归，理解递归的本质。
